# はじめに

3GPP仕様をLLMから検索・参照するためのMCPサーバーを作って公開しました。

- リポジトリ: https://github.com/higebu/3gpp-mcp

Claude Code や Claude Desktop、VS Code Copilot などのMCPクライアントから、3GPPの仕様書をセクション単位で検索したり、相互参照を辿ったり、図表やOpenAPI定義を取り出したりできます。

# なぜ作ったか

普段から3GPP仕様を読む機会があるのですが、3GPP仕様には以下のような扱いにくさがあります。

- 仕様が数千ドキュメントに分散していて、目的の情報がどこにあるか探すだけでも一苦労
- 1つの仕様が数百ページあり、そのままではLLMのコンテキストウィンドウに収まらない
- 配布形式が基本的にWordファイルで、プログラムから扱いにくい
- 仕様間の相互参照が複雑で、ドキュメントを行き来しないと意味が取れない
- 表やフローダイアグラムなど、情報密度の高い図表が多い

LLMに3GPP仕様の調べ物を手伝ってほしい場面は多いのですが、上記の理由でそのままでは難しく、毎回該当箇所を手で抜き出して貼り付けるのも大変でした。そこで、MCPサーバーとしてまとめて公開することにしました。

# 何ができるか

主な機能は以下の通りです。

- SQLite FTS5 による全文検索
- ドキュメントの階層構造を保持したセクション単位のナビゲーション
- 仕様間の相互参照の追跡
- 仕様書中の画像抽出 (EMF/WMF からPNGへの変換)
- OpenAPI 定義の抽出と表示
- ブラウザから仕様を眺めるためのWeb UI
- 複数の3GPPリリースに対応
- stdio と HTTP の両方に対応していて、リモートにデプロイして共有することも可能

# 設計のポイント

最初はベクトル検索ベースのRAGも考えたのですが、最終的には「構造を保ったままパースしてSQLiteに格納する」方式にしました。

3GPP仕様は章番号や節構造、表、相互参照といった構造そのものが重要な情報なので、機械的にチャンク分割するとその構造が壊れてしまい、結果としてLLMが正しく文脈を追えなくなることが多いです。構造を保ったまま格納しておけば、LLMから「この節の続きを取りたい」「この参照先を開きたい」といった要求にそのまま応えられます。

実装はGoで、ストレージはSQLite (FTS5) にしました。シングルバイナリで配布できる手軽さと、全文検索を外部依存なしに実現できる点が決め手です。

# 使い方

インストールは `go install` 一発です。Go 1.26 以上が必要で、Word形式の仕様書を変換するために LibreOffice があると便利です。

```shell
go install github.com/higebu/3gpp-mcp/cmd/3gpp-mcp@latest
```

MCPクライアントへの登録方法やデータの取り込み手順は README を参照してください。

セットアップが終われば、たとえば Claude Code から「TS 24.501 における5G NASの認証手順を、関連する図表も含めて要約して」といった依頼を投げると、3gpp-mcp が該当セクションと図を取り出してきて、それをもとにLLMが回答してくれます。
